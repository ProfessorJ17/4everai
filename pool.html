🔧 OPERATOR SETUP GUIDE
ℹ This guide is for the site operator. Regular users just sign up and click Mine.
1

Firebase (already set up — use your existing project)

Use the same Firebase project as your existing havoc.html. Paste your existing firebaseConfig into the OPERATOR CONFIG block in the script. Enable Firestore if not already enabled.

2

Deploy WebSocket→Stratum Proxy (Free on Render.com)

Browsers can't open raw TCP sockets. This tiny Node.js app bridges your browser workers to MoneroOcean's stratum port.

// server.js const net = require('net'); const WebSocket = require('ws'); const wss = new WebSocket.Server({ port: process.env.PORT || 8080 }); wss.on('connection', ws => { const tcp = net.createConnection(3333, 'gulf.moneroocean.stream'); ws.on('message', d => tcp.write(d)); tcp.on('data', d => { try { ws.send(d.toString()); } catch(e){} }); ws.on('close', () => tcp.destroy()); tcp.on('close', () => { try { ws.close(); } catch(e){} }); tcp.on('error', () => { try { ws.close(); } catch(e){} }); ws.on('error', () => tcp.destroy()); }); console.log('HAVOC XMR Proxy running'); // package.json // { "dependencies": { "ws": "^8.0.0" } } // Deploy free on render.com: // New Web Service → GitHub repo → Node → start: node server.js // Your URL: wss://your-app.onrender.com
3

MoneroOcean — 0% Fee Pool

MoneroOcean is a free, 0% fee Monero mining pool with auto-algorithm switching. All you need is your XMR wallet address. No registration. Payouts go to your pool wallet, which you then split to users via the Admin Panel.

Pool: gulf.moneroocean.stream:3333 Username: YOUR_POOL_XMR_WALLET_ADDRESS Password: x Worker suffix: .workerName (appended automatically per user)

Firestore Security Rules

rules_version = '2'; service cloud.firestore { match /databases/{database}/documents { match /users/{uid} { allow read, write: if request.auth.uid == uid; } match /shares/{id} { allow read: if request.auth != null; allow create, update: if request.auth.uid == request.resource.data.uid; } match /pool/{doc} { allow read: if true; allow write: if false; } match /payouts/{id} { allow read: if request.auth.uid == resource.data.uid; allow write: if false; } } }
